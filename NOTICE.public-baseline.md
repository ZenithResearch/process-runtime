# Public source baseline

This is an owner-approved clean Git baseline. Original repositories, histories,
uncommitted work, credentials and installed data remain private and unchanged.
No new project reuse license is granted here; existing per-file/per-crate licenses
and imported third-party notices retain their scope. No package-registry release
or production authority is implied by public source availability.

Review examples are de-identified protocol demonstrations. They are not the
original private qualification evidence. Their transformed hash bindings are
regenerated and the public regression suite is rerun before publication.
